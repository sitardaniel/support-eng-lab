# Support Engineer Lab

Break-and-fix practice tickets for customer-facing support engineers. The product in the story runs on Kubernetes inside customers' closed, air-gapped networks. You fix things through someone else's hands.

**Play in the browser:** https://sitardaniel.github.io/support-eng-lab/

Every ticket has a working terminal in the page. It's a simulator: it knows the commands each ticket needs (kubectl, crictl, ctr, openssl, curl, tcpdump, tshark, jq, grep, awk, sort, uniq...), with pipes, and it checks whether your fix actually worked.

**Real cluster:** [![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/sitardaniel/support-eng-lab?quickstart=1)

The Codespace builds a single-node k3s cluster with k3d and cuts it off from the internet, like a customer site. The first boot takes about 5 minutes.

```bash
lab list            # everything you can do
lab break 102       # inject a ticket's fault
lab check           # is the customer happy yet?
lab reset           # back to healthy
lab chaos           # random fault, no hints
lab airgap status   # prove the node can't pull images
lab node crictl images
```

## Tickets

| Day | Ticket | Skill |
| --- | --- | --- |
| 1 | 100 Set up the real lab | Codespace, air gap |
| 2 | 101 New module won't start | Air-gapped images, `:latest` pull policy |
| 2 | 102 Running but nothing connects | NetworkPolicy, DNS |
| 2 | 103 Worker restarts, logs are clean | OOMKilled, exit 137, dmesg |
| 2 | 104 Nothing new will schedule | DiskPressure, eviction (browser only) |
| 3 | 201 Portal cert error | CA trust, SAN, expiry and clock drift |
| 3 | 202 Three sites can't connect | tcpdump / tshark: refused vs timeout vs TLS alert |
| 4 | 301 RCA from a log bundle | jq, grep, awk on JSON logs |
| 4 | 302 Support bundle script | Read-only triage |
| 4 | 303 Data layer drill | Elasticsearch, Kafka, MongoDB |
| 5 | 401 The first response | Customer writing |
| 5 | 402 Follow-the-sun handover | Shift handover |
| 5 | 403 Chaos round | End to end, timed |

## Repo layout

```
index.html, assets/      the site (plain HTML/CSS/JS, no build step)
assets/shell.js          tokenizer, pipes, text tools
assets/jq.js             a small jq interpreter
assets/k8s.js            the simulated cluster and node
assets/tickets.js        every ticket: story, fault, fix check
lab/lab                  the CLI used in the Codespace
lab/setup.sh             Codespace setup
lab/data/bundle.jsonl    the log bundle for ticket 301 (generated by genlogs.py)
.devcontainer/           Codespace definition
```

Progress and drafts are saved in your browser only.
